Detailed Description

Abstrakcyjna klasa bazowa reprezentująca zgłoszenie (Ticket) w systemie.

Klasa definiuje wspólne właściwości i zachowania wszystkich typów zgłoszeń. Stanowi podstawę dla klas dziedziczących takich jak BugTicket, FeatureRequestTicket czy TechnicalTicket.

Zawiera mechanizmy:

  • zarządzania statusem zgłoszenia,
  • historii zmian,
  • identyfikacji zgłoszeń (GUID + numer),
  • śledzenia ostatniej akcji.
