Detailed Description

Interfejs definiujący kontrakt repozytorium ticketów.

Odpowiada za operacje dostępu do danych (warstwa persystencji), niezależnie od sposobu ich przechowywania.

Może być zaimplementowany np. jako:

  • pamięć (InMemory),
  • baza danych,
  • plik.
