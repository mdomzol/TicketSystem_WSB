Detailed Description

Zestaw scenariuszy testowych oraz opis weryfikacji funkcjonalności systemu TicketSystem.

Klasa nie zawiera automatycznych testów jednostkowych. Służy jako dokumentacja scenariuszy testowych wykonanych manualnie w ramach weryfikacji działania systemu.

Testy obejmują warstwy:
