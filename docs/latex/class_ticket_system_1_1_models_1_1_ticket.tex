\doxysubsection{Detailed Description}
Abstrakcyjna klasa bazowa reprezentująca zgłoszenie (\doxylink{class_ticket_system_1_1_models_1_1_ticket}{Ticket}) w systemie. 

Klasa definiuje wspólne właściwości i zachowania wszystkich typów zgłoszeń. Stanowi podstawę dla klas dziedziczących takich jak \doxylink{class_ticket_system_1_1_models_1_1_bug_ticket}{Bug\+Ticket}, \doxylink{class_ticket_system_1_1_models_1_1_feature_request_ticket}{Feature\+Request\+Ticket} czy \doxylink{class_ticket_system_1_1_models_1_1_technical_ticket}{Technical\+Ticket}.

Zawiera mechanizmy:\+
\begin{DoxyItemize}
\item zarządzania statusem zgłoszenia,
\item historii zmian,
\item identyfikacji zgłoszeń (GUID + numer),
\item śledzenia ostatniej akcji. 
\end{DoxyItemize}
