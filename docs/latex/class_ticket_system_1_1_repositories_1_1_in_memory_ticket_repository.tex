\doxysubsection{Detailed Description}
Implementacja repozytorium ticketów przechowująca dane w pamięci. 

Klasa realizuje wzorzec Repository. Dane przechowywane są w liście w pamięci RAM, bez użycia bazy danych. Odpowiada wyłącznie za operacje CRUD na obiektach \doxylink{class_ticket_system_1_1_models_1_1_ticket}{Ticket}.
