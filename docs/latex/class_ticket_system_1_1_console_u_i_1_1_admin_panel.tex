\doxysubsection{Detailed Description}
Panel administratora systemu ticketów. 

Umożliwia przeglądanie zgłoszeń, podgląd szczegółów oraz zmianę statusu istniejących ticketów.

Logika wyświetlania została przeniesiona do klasy Ticket\+Console\+Printer, dzięki czemu panel odpowiada wyłącznie za obsługę menu i przepływu użytkownika.
