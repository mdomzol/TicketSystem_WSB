Interfejs definiujący kontrakt dla serwisu obsługującego zgłoszenia (\doxylink{class_ticket_system_1_1_models_1_1_ticket}{Ticket}). 

Odpowiada za operacje biznesowe wykonywane na zgłoszeniach, takie jak tworzenie, zmiana statusu oraz pobieranie listy ticketów.
