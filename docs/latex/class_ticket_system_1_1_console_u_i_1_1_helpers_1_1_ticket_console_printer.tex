\doxysubsection{Detailed Description}
Klasa pomocnicza odpowiedzialna za wyświetlanie i obsługę zgłoszeń w konsoli. 

Zawiera logikę prezentacji danych oraz interakcji użytkownika związanych z wyborem, podglądem i zmianą statusu ticketów.

Klasa stanowi warstwę UI Helper i współpracuje z \doxylink{class_ticket_system_1_1_services_1_1_ticket_service}{Ticket\+Service}.
