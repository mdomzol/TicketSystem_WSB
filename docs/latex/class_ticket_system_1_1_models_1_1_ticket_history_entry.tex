\doxysubsection{Detailed Description}
Reprezentuje pojedynczy wpis w historii zgłoszenia. 

Klasa służy do przechowywania informacji o zmianach i zdarzeniach związanych z Ticketem (np. zmiana statusu, utworzenie zgłoszenia).

Każdy wpis jest niemutowalny po utworzeniu.
