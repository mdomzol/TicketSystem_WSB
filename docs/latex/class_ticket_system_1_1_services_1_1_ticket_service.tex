\doxysubsection{Detailed Description}
Warstwa logiki biznesowej systemu ticketów. Odpowiada za operacje na zgłoszeniach, takie jak tworzenie, zmiana statusu oraz pobieranie listy ticketów. 

Klasa działa jako pośrednik pomiędzy warstwą UI a repozytorium danych. Nie przechowuje danych bezpośrednio — deleguje operacje do \doxylink{interface_ticket_system_1_1_interfaces_1_1_i_ticket_repository}{ITicket\+Repository}.
